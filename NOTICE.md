# Attribution and modification notice

Hevea Vision Pro is an **unofficial tribute and independent spatial-computing research prototype**. It is not an official release of the Hévéa team, CNRS, Université Claude Bernard Lyon 1, Université Grenoble Alpes, or the authors of the cited papers.

The original flat-torus implementation was written by Vincent Borrelli, Saïd Jabrane, Francis Lazarus, and Boris Thibert for the Hévéa project. The upstream source is available at <https://github.com/HeveaProject/Hevea> and is licensed under GNU GPL version 3 or, in individual source headers, any later version.

Primary research references:

- Vincent Borrelli, Saïd Jabrane, Francis Lazarus, and Boris Thibert. “Flat tori in three-dimensional space and convex integration.” *PNAS* 109(19), 7218-7223 (2012). <https://doi.org/10.1073/pnas.1118478109>
- Evangelis Bartzos, Vincent Borrelli, Roland Denis, Francis Lazarus, Damien Rohmer, and Boris Thibert. “An Explicit Isometric Reduction of the Unit Sphere into an Arbitrarily Small Ball.” *Foundations of Computational Mathematics* 18, 1015-1042 (2018). <https://doi.org/10.1007/s10208-017-9360-1>

The Swift and RealityKit implementation in this repository was begun by Alok Singh with OpenAI Codex on 2026-08-29. It is a new implementation unless a file says otherwise. Explanatory real-time surfaces deliberately trade frequency and numerical fidelity for interactive inspection; the application labels them as proxies.
